Entry for the make.fun bounty **The Router Confesses** ($2): one line a home Wi-Fi router says to excuse itself for dropping the connection at a movie's climax.

> You unplugged me in 2019 and called me useless. I waited six years for this exact scene. Enjoy the silence.

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with in-code gate checks: 1–200 characters, non-blank, exactly one line.
